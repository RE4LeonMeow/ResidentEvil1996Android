# Resident Evil Android 1.11

Version 1.11 brings improved mod support, a new cheat and fixes for foldable
phones.

- **Improved mod support:** expanded compatibility for prepared mods, with
  support for custom starting setups, room resources, timers and separate
  campaign saves.
- **Background fixes:** fixes striped or distorted backgrounds in supported
  mods, including elevator and underground/sewer scenes.
- **Widescreen timer:** keeps countdown text visible in 16:9.
- **Ignore player (freeze enemies):** a new experimental option in
  **Settings → Cheats**. Autonomous enemies stop moving and attacking, while
  hits, deaths and scripted actors keep updating. It turns off when you return
  to the launcher.
- **Foldable phone fix:** handles folding, unfolding and display-size changes
  without recreating the game activity and returning to the launcher. Touch
  controls refresh for the new screen size, and held inputs are released.

Install the new APK over your existing installation to keep saves, settings
and installed mods. You still need your own USA PC game files. Find mods in
**#mods on the Discord server**, and install compatible ZIPs through **Mods → +**.
Follow each pack's instructions and compatibility report.

Mod compatibility depends on the pack. Windows DLL/ASI plugins are unsupported;
the helper does not automatically convert every PC mod. Report bugs through
[GitHub Issues](https://github.com/RE4LeonMeow/ResidentEvil1996Android/issues),
including the build number and **Settings → Logs → Copy report** when possible.
