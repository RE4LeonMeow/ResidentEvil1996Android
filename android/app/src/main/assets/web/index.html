Mods · help
Find community packs in #mods on the Discord server (Resident Evil 1996 Porting). Use packs from confirmed modders. Select your own USA GOG game folder, then tap Mods → + and choose a ZIP.
Install directly: texture packs made for this Android port and compatible PC model/sound replacements with their original game folders. You can make your own textures too: backgrounds, character skins, items and more. See the guide for the supported formats.
Prepare first: supported Classic REbirth XML translations need their extracted manifest.txt, encoding.xml, font and resource folders together in one ZIP. The preparation tool and manual phone steps are in the guide. Extract RAR/7z and split archives first; ZIP the extracted contents.
Example: the full official RE_SHDP_1.1.zip is one supported texture/movie pack. Its small patch and GitHub source ZIP are not the full pack.
Needs separate support: arbitrary hires layouts, other font formats and assets for different game versions. Translation add-ons also need their base translation. Windows DLL/ASI plugins, executable patches and engine changes do not run as imported mods.
Read the Compatibility report after import. Checkboxes enable or disable mods; the top mod wins conflicts. Keep translations above packs replacing the same fonts or UI. Changes apply next launch. You can edit a mod's name and description. Original game files and saves stay separate.
