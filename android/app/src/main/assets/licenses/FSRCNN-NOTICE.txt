The original pretrained graph is converted, without retraining, to C++ float
constants by tools/hd/import_fsrcnn.py. Port additions implement tiled SIMD
inference, alpha-preserving colour reconstruction, final-size resampling and
optional bounded edge sharpening after neural reconstruction.
No TensorFlow or OpenCV runtime is distributed with this port.

Model architecture: Chao Dong, Chen Change Loy, Xiaoou Tang,
"Accelerating the Super-Resolution Convolutional Neural Network", ECCV 2016.
The upstream implementation uses a sub-pixel layer in place of transposed
convolution (Shi et al., CVPR 2016).
